# Third-party software and data

cfCNV runs other people's tools and reads public data. It does not change their licences, and you must follow each
one. The table says what each licence is (as stated in the tool's own repository or package) and how cfCNV obtains
the tool. "Image" means it is inside one of the published cfCNV container images; the source and licence text of
every packaged tool remain available at the link given.
