This is a teaching model: Poisson read counts, a smooth GC-like coverage wave that normalisation removes only partly, and a simple binary segmentation. Real callers differ in each step, which is what the benchmark below measures.

What eight callers found

The same BAM files went to QDNAseq, ichorCNA, BIC-seq2, CNVkit and Spectre, and to three machine-learning callers, CNV-MEANN, dudeML and LYCEUM. Truth came from three places: 30 events inserted into healthy cfDNA in each of 5 replicates, tumour–normal mixtures of the NIST HG008 cell line, and plasma from 25 people without cancer.

Score your own calls

Run any caller on the Simulation 1 BAMs and paste its calls here as chrom start end type, with gain or loss as the type (dup, amp, del, or a copy number also work). Coordinates are GRCh37. Matching is one-to-one at a reciprocal overlap you choose, the paper's rule at 0.5. Everything runs in your browser; nothing is uploaded.

Run the workflow

Every analysis on this page comes from one Nextflow workflow with a container for each tool. It needs Nextflow 24.04 or later and Singularity, Apptainer or Docker.

nextflow run FPalizban/cfCNV -r main -profile singularity,slurm \
    --input samples.csv --genome GRCh38 --fasta GRCh38.fa \
    --downsample 1,0.1 --outdir results

--mode simulate rebuilds Simulation 1 with the paper's truth sets and trains CNV-MEANN and dudeML, --mode mix builds tumour–normal mixtures, and --mode score scores any call file. BIC-seq2 is free for academic use only and is not distributed in an image: pass your own with --bicseq2_container. Licences of all included tools are listed in the repository.
