Benchmark · cell-free DNA · copy number

Which copy-number caller can you trust in cfDNA?

cfCNV tests classical and machine-learning CNV/CNA callers on low-pass cell-free DNA, using simulated events with known truth, NIST HG008 tumour–normal mixtures, and real plasma. Explore how depth, tumour fraction and bin size change what a caller can see, then score your own calls against the same truth.

01 · The signal

A tumour copy-number change is a small shift buried in counting noise

Every caller reads the same thing: how many reads fall in each genomic bin, relative to the expectation. Move the sliders to see how sequencing depth, tumour fraction and bin size decide whether a change stands out. This is a teaching model with Poisson counting noise and smooth GC-like waves, segmented with a simple binary-segmentation caller.

04 · Score your caller

Run your tool on our truth, paste the calls, see where it lands

Simulation 1 replicates contain 30 known events each (GRCh37, 50 kb–50 Mb, gains and losses). Paste your calls as BED-like lines: chrom start end type, where type is gain/loss (dup, amp, del, or a copy number also work). Scoring runs in your browser; nothing is uploaded.

The example is a synthetic call set made for this demo from replicate 1: some events found with shifted breakpoints, some missed, and three false calls.

06 · Run it

Reproduce the benchmark

The workflow, containers and benchmark files are being packaged for release with the paper. Until then the repository holds the per-tool scripts used for the runs shown here.

Planned interface

nextflow run FPalizban/cfCNV \
  -profile docker,slurm \
  --input samples.csv \
  --genome GRCh38 \
  --callers qdnaseq,ichorcna,bicseq2,cnvkit,spectre \
  --truth truth.bed \
  --outdir results/
